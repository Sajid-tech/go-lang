WHY GOLANG

1.Build Time - ci-cd pipeline , there it build fast 
2.Fast Startup - after deployed when run the application  - when compile - machine code
3.Performance and Efficiency - efficient way to use cpu becuz it has goroutine( light weight thread)
4.Concurrency model- multithreaded multicore , use efficient way to use thread 
5.Static typing and compilation - define type on varibable - so if any error come than it show in compile time


# Run go file

-> step 1 : build -> go build 'file path'
-> step 2 : exe -> ./main   -> executable main

OR - if you just want to run not build than 

-> go run 'file path'
